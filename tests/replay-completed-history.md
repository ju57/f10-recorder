# Completed replay history checks

`--replay-completed-history-plan` previews fourteen native controls through the
real session history, rooted admission and ReplayCache/ReplaySaveExport paths.
Run `--replay-completed-history-checks <fresh-root>` only with an independently
reviewed exact-helper plan and external bounds. The fresh root must be under
ignored artifacts; previous failed attempts stay intact.

The helper writes tiny structural coded-byte fixtures and controlled dummy
output, not decodable-picture qualification. It uses immutable native file and
directory owners, real background parser tasks, independent request readers,
forced-copy/link aliases, cancellation, pruning/ref retirement and actual forced
and late-configuration fallback callsites. Codec invocation is intercepted; no
child, encoder, decoder, UI, desktop/system/microphone acquisition, playback,
installation, startup, vendor or account-catalog change occurs.

Bounds: one helper, 60 s cooperative work, 75 s outer plus5 s drain, 1 MiB fixture
outputs, 64 MiB total diagnostics, 512 MiB working set, 4096 handles and60 GB
free floor. Polled limits are not quotas. Unknown closure retains owners and
fails; no retry, media collection or qualification follows automatically.
